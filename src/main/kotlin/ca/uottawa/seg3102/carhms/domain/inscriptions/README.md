# Nom du sous-domaine : Inscriptions

**Classification :** Cœur

**Justification :** Confirmation, liste d'attente ordonnée et promotion automatique : logique propre au système qui le différencie

## Courte description du sous-domaine

Ce sous-domaine suit la participation des randonneurs aux randonnées. Il représente chaque inscription et sa place éventuelle dans la liste d’attente, tout en coordonnant les changements provoqués par les places disponibles et les annulations.
