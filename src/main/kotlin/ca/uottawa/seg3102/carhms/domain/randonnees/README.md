# Nom du sous-domaine : Randonnées

**Classification :** Cœur

**Justification :** Cycle de vie (ouverte, complète, fermée, annulée), règles de création (saison, date limite, certification) et suivi de qui fait chaque étape : c'est la raison d'être du système.

## Courte description du sous-domaine

Ce sous-domaine encadre les événements de randonnée du club, depuis leur création jusqu’à leur fermeture ou leur annulation. Il regroupe les conditions de planification et le suivi des changements d’état prévus par CAR-Req-01.
