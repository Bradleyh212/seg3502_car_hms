# Nom du sous-domaine : Sentiers (CCN)

**Classification :** Support

**Justification :** Données publiées par la CCN; le club ne les tient pas lui-même. Le système les consulte pour valider les randonnées.

## Courte description du sous-domaine

Ce sous-domaine donne accès aux renseignements sur les sentiers publiés par la Commission de la capitale nationale. Ces données externes permettent de choisir un parcours réel et de vérifier les conditions applicables à une randonnée du club.
