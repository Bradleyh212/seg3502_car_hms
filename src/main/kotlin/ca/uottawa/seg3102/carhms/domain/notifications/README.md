# Nom du sous-domaine : Notifications et rappels

**Classification :** Générique

**Justification :** Courriels de confirmation, d'annulation et de rappel (avec météo) : service standard, à acheter ou à intégrer.

## Courte description du sous-domaine

Ce sous-domaine transmet les messages prévus aux randonneurs concernés par une inscription ou une randonnée. Il rassemble les communications liées à la participation et les rappels envoyés avant le départ.
