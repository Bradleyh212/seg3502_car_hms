# Nom du sous-domaine : Rapports d'utilisation

**Classification :** Support

**Justification :** Statistiques par sentier et période pour les administrateurs; utile mais non différenciant.

## Courte description du sous-domaine

Ce sous-domaine répond aux besoins de consultation des administrateurs concernant l’utilisation des sentiers par le club. Il produit les statistiques prévues par CAR-Req-01 à partir des randonnées et de leurs participations pour une période déterminée.
