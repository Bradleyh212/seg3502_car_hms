# Nom du sous-domaine : Authentification et autorisation

**Classification :** Générique

**Justification :** Connexion, déconnexion et rôles : problème résolu par des solutions existantes.

## Courte description du sous-domaine

Ce sous-domaine établit l’identité des utilisateurs et encadre leurs droits d’accès aux fonctionnalités. Il distingue les visiteurs des utilisateurs enregistrés et applique les autorisations correspondant aux rôles décrits dans CAR-Req-01.
