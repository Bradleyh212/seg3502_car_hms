# Nom du sous-domaine : Admissibilité à une randonnée

**Classification :** Cœur

**Justification :** Le club veut un meilleur contrôle sur l'association entre événements et membres (niveau d'habileté, adhésion active) : c'est un autre facteur de différenciation.

## Courte description du sous-domaine

Ce sous-domaine détermine si un randonneur peut s’inscrire à une randonnée selon les conditions décrites dans CAR-Req-01. Il soutient également la présentation des randonnées correspondant au niveau d’habileté d’un randonneur connecté.
